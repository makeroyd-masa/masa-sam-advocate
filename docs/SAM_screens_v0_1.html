SAM — Screen Set v0.1

Member-facing screens for the SAM medical-bill advocate, drawn on the existing MASA app surfaces. Maps to PRD v0.3 §1.3 (universal SAM), §4 (intake checkpoint), and §7 (answer card). Each frame is captioned with its stage and the app.db fields it writes.

Horizon — primary / advocate actions Tide — leverage / secondary Flare — links & escalation Shine — honesty / caution node
1 · Universal entry — no dedicated SAM page

A persistent FAB carries the full capability set everywhere; the launch surface pre-seeds the workflow. Writes cases.entry_point + cases.seed_intent.

2 · Intake — the checkpoint pattern (Stages 0–4)

Light stages live in the bottom-sheet; committing to line-item or appeal entry expands it to near-full. State machine in cases.current_stage + machine_context (resumable).

3 · Answer cards — one structure, three flows

Every output: headline → the number → why (with citations) → one next action → “appears to / likely” framing → human-advocate escalation. Persisted to answer_cards + card_citations.
